# PKI with Root CA, Signing CA and TLS certificate, served by Apache Tomcat

CMPE 272 assignment. This repo builds a two-tier PKI with OpenSSL, following the
[Simple PKI tutorial](https://pki-tutorial.readthedocs.io/en/latest/simple/), and uses the
issued TLS certificate to run Apache Tomcat over HTTPS, following the
[Tomcat SSL/TLS how-to](https://tomcat.apache.org/tomcat-7.0-doc/ssl-howto.html).

```
CMPE272 Lab Root CA          (self-signed, RSA 4096, 10 years, CA:true)
  └── CMPE272 Lab Signing CA (signed by Root, RSA 3072, CA:true, pathlen:0)
        └── www.cmpe272.test (TLS server cert, RSA 2048, 2 years,
                              SAN: www.cmpe272.test, localhost, 127.0.0.1)
                └── Tomcat 11 HTTPS connector on :8443 (PKCS#12 keystore)
```

## Layout

| Path | Purpose |
|---|---|
| `etc/root-ca.conf` | OpenSSL config for the Root CA (`req` + `ca` sections) |
| `etc/signing-ca.conf` | OpenSSL config for the Signing CA, incl. `server_ext` / `email_ext` |
| `etc/server.conf` | CSR config for the TLS server certificate (SAN from `$SAN`) |
| `scripts/01-root-ca.sh` | Tutorial step 1: create the Root CA |
| `scripts/02-signing-ca.sh` | Tutorial step 2: create the Signing CA, signed by the Root CA |
| `scripts/03-tls-cert.sh` | Tutorial step 3+4: TLS cert, chain, CRLs, DER files, PKCS#12 |
| `scripts/build-pki.sh` | Runs steps 1 to 3 |
| `scripts/04-setup-tomcat.sh` | Downloads Tomcat (SHA-512 checked), installs keystore and HTTPS connector |
| `scripts/05-verify.sh` | Verifies the deployment with `openssl s_client`, `curl` and a Java client |
| `tomcat/ssl-connector.xml` | The `<Connector>` added to Tomcat's `server.xml` |
| `tomcat/webapp/pki-demo/` | Demo JSP that shows the TLS protocol/cipher of the request |
| `ca/`, `certs/`, `crl/` | Generated public outputs (certificates, CSRs, CRLs, CA databases) |
| `docs/` | Logs from the actual run and a screenshot |

Private keys (`*.key`), the PKCS#12 keystore (`*.p12`) and `secrets.env` are listed in
`.gitignore` and are never committed.

## Requirements

OpenSSL 3.x, Java 11+ (tested with Temurin 21), `curl`, `python3`. Tested on macOS.

## Run it

```bash
# Passphrases. Leave these unset to be prompted interactively, as in the tutorial.
export ROOT_CA_PASS='...' SIGNING_CA_PASS='...' KEYSTORE_PASS='...'

./scripts/build-pki.sh          # Root CA -> Signing CA -> TLS certificate
./scripts/04-setup-tomcat.sh    # Tomcat 11.0.29 + HTTPS on 8443
tomcat/apache-tomcat-11.0.29/bin/startup.sh
./scripts/05-verify.sh          # chain, hostname and trust checks
tomcat/apache-tomcat-11.0.29/bin/shutdown.sh
```

Open <https://localhost:8443/pki-demo/>. Browsers show a warning until you import
`ca/root-ca.crt` as a trusted root, because it is a private CA. On macOS:
Keychain Access → System → import `root-ca.crt` → Trust → "Always Trust".

Start over with `./scripts/clean.sh`.

## Changes from the tutorial

* SHA-256 instead of SHA-1 and larger keys (4096/3072/2048), because SHA-1 certificates are
  rejected by current TLS clients.
* `prompt = no` with fixed DNs, and optional `-passin/-passout env:` so the build can run
  unattended.
* Tomcat 11 instead of Tomcat 7 (end of life). The connector uses the `<SSLHostConfig>` /
  `<Certificate>` syntax available since Tomcat 8.5. The Tomcat 7 attribute form is shown in a
  comment in `tomcat/ssl-connector.xml`.
* A PKCS#12 keystore built with `openssl pkcs12` instead of `keytool -genkey`, so the key is
  generated by our PKI rather than self-signed by keytool.
